# RONIN Mental Android

Aplicación Android que empaqueta la herramienta web original **PSYCHIATRIC-SCANNER Ω · RONIN MENTAL v2.0** en un WebView local.

## Idioma y uso responsable
- La aplicación está únicamente en castellano; no incluye traducción inglesa parcial.
- Herramienta de apoyo informativo, no sustituye la evaluación profesional ni constituye un dispositivo médico validado.
- Las escalas y los módulos de riesgo deben interpretarse por profesionales cualificados. Ante peligro inmediato, contacte con emergencias locales.
- Las notas y el historial se almacenan en el almacenamiento local del navegador; no se ha añadido un servidor de sincronización. No incluya datos identificativos si comparte el dispositivo.

## Compilar
En GitHub, abra **Actions → Build Android APK → Run workflow** (o haga push a main). Descargue el artefacto `ronin-mental-debug-apk` de la ejecución completada. Es un APK de depuración, no una versión firmada para Play Store.
